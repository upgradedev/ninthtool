Ninth Tool

Ninth Tool executes your page's WebMCP tools in the browser and shows which promises the standard silently drops, with the command that reproduces each one.

Named for the tool that has to disappear. A page registers eight tools, a ninth appears when the state that justifies it appears, and it is supposed to withdraw when that state goes away. Write the withdrawal the obvious way and it never happens, and nothing is thrown.

Run it

This drives the subject page below through your browser's own WebMCP and judges what happened. Nothing is sent anywhere, nothing is stored, and no tool that writes is ever called.

The behaviours

The subject page

A real page on this origin with two forms promoted to tools by HTML attributes. It is loaded in a frame and driven live. You can fill either form in yourself: they are ordinary controls when no agent is involved.

What this does not do, and why

It does not scan other people's sites. A page cannot reach another origin's tool surface. The tools Permissions Policy defaults to self, and a cross origin frame was measured contributing zero tools while a same origin frame contributed its whole list. That boundary is the reason this is a suite you run against your own page rather than a scanner you point at a stranger's.

To audit a page on another origin, run the command line runner against it from a machine you control:

node bin/ninthtool.mjs https://your-page.example

No writes, anywhere, ever. The probe calls only tools it registered itself, plus the two forms this subject page declares. No account, no backend, no crawling, and no verdict is published about anybody's named page.

Where the numbers come from

Every stored measurement in the catalogue was taken on 2026-09-01 against Chrome 152.0.7977.65 launched with --enable-features=WebMCP. Nothing in it is copied from documentation. Where documentation disagrees with the measurement, the row says what the documentation promised and is reported as a divergence rather than as a defect in your page.

The reading above is not that stored measurement. It is what your browser did, just now, and it may differ. Where it does, your browser is the newer fact.
