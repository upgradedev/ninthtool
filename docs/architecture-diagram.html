3 The auditor is a WebMCP page

nt_run_audit

Runs every probe against the live page. Not marked read only, because it drives forms.

nt_list_behaviours

Every row with its group, its subject and the promise being tested. Read only.

nt_explain_behaviour

One row in full: the promise, what the draft says, what was measured, and the command that reproduces it. Read only.

nt_get_findings Three tools are published at rest and a fourth while findings exist. It is withdrawn when they clear, so the behaviour this suite is named for runs on itself.

4 Gathering is not deciding

Strict separation

The probe records what happened and has no idea what a pass is. The judge is pure and cannot reach a browser.

Every rule ships a mutation

Each rule is paired with an input that proves it can go red. A gate never watched failing is not a gate.

Honest abstention

A row that could not run says so. It is never counted as a pass.

Reproduce any row node bin/ninthtool.mjs --behaviour C3
